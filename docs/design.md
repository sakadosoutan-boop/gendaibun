# 現代文スキーマ学習アプリ 設計メモ

設計はQ&A形式（グリル）で詰めている。決定済みの事項のみ記録し、未決事項は末尾に置く。

## 1. 利用者とゴール（Q1）

- 利用者：大学受験生
- 配布形態：高校教員が作成し、担当する生徒に配布する
- 対象：**評論文のみ**（小説は対象外）
- 記述問題：後回し（当面は選択式・短答で扱える範囲）
- 利用シーン（仮）：スマホで、スキマ時間に1回10分前後
- 成功の定義（仮）：初見の評論文でも、テーマを見た瞬間に「対立軸」と「筆者の主張の向き」を予測できる

## 2. スキーマのモデル（Q2）

- 2層構造
  - **テーマスキーマ**：頻出テーマごとの対立軸・キーワード・筆者の典型的な立場
  - **読解スキーマ**：論理展開の型（対比、具体→抽象、譲歩→主張、言い換えなど）と設問の型（傍線部説明、理由説明、内容一致など）
- 学習の主軸：**テーマ単位で進め、技法は横断タグとして管理する**（C案）
  - すべての問題に「使う技法」をタグ付けし、技法ごとの習熟度も記録する → 弱点に応じた出題に使う
- テーマスキーマは「**二項対立マップ**」として見える化する（仮採用）

## 3. UIの方針（Q2で要望）

- スキマ時間で使える軽さ
- 読み進めるうちに**テーマ群を獲得していく過程が見える**
- 少しユーモアのあるUI

## 4. コンテンツの調達（Q3）

3層構造で扱う。

| 層 | 中身 | 位置づけ |
|---|---|---|
| ① ミニ評論（自作） | 入試頻出のテーマと論理構造をなぞった400〜800字の文章と設問 | アプリの主役 |
| ② 出典データ＋公式リンク | 実際の入試の書誌情報（大学・年度・著者・作品名）、テーマ・構造タグ、大学公式ページへのリンク | 頻出度の根拠、「本物に挑戦」ボタン |
| ③ 本文の抜粋配信（将来） | 著作権法35条の範囲で、ログインした自分の生徒にだけ配る | 県教委のSARTRAS契約が確認できたら後付けする |

著作権についての注意：

- 入試本文の著作権は原著者にある。大学公式HPの過去問は閲覧用であり、再配布の許諾ではない（国語は本文が省略されていることも多い）。リンクを張るのは問題ない。
- ミニ評論は**骨組み（テーマ・対立軸・筆者の立場・論理展開の型）だけから生成する**。入試本文をそのままAIに渡して書き換えさせると、翻案（27条）に当たるおそれがあるため。
